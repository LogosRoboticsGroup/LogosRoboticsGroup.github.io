# Legacy SMR project URL

This organization Pages repository preserves the published SMR project address after the project repository transfers to [LogosIntelligenceLab/SMR](https://github.com/LogosIntelligenceLab/SMR).

- `SMR/index.html` redirects the old project homepage to https://logosintelligencelab.github.io/SMR/ and preserves query parameters and section anchors.
- `SMR/paper.pdf` preserves the old direct PDF download.
- `404.html` forwards browser visits to other `/SMR/` paths to the corresponding path on the new site.
- Other organization project paths are not redirected.

Publish from the `main` branch, root directory. Keep the previous `LogosRoboticsGroup/SMR` repository name unused so GitHub's automatic repository redirects remain intact.
